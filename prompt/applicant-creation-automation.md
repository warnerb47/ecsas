# Prompt 1
Voici l'interface de création d'une demande [capture_create_application]. J'aimerai mettre en place une page qui charge les documents CNI ou Extrait de naissance du bénéficiaire, la demande manuscrite, le certificat de domicile, etc. Et à partir de ces documents un LLM qui tourne en local sur l'application scan les documents et préremplis les formulaires. Proposes moi un design au format HMTML + tailwind CSS sur lequel on peut uploader les documents par demande et lancer le scan en background. Après avoir scan tous les documents un écran de validation permet de vérifier les informations et corriger à la volet.

# Prompt 2
Proposes moi un design au format HMTML + tailwind CSS pour la page "liste des demandes en cours de Scan & PRÉ-REMPLISSAGE INTELLIGENT".
